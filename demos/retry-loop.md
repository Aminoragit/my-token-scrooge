# Retry-loop demo

1. Install the balanced preset with `mts setup`.
2. Simulate `read node_modules/pkg/index.js` for a detected target.
3. Simulate the equivalent shell forms with `cat` and `Get-Content` in the same session.
4. Observe guidance on the first attempt, a bounded substitute on the second, and `MTS_CIRCUIT_OPEN` on the third.
5. Open `mts savings today` and confirm replacement and retry bytes are subtracted.

This script is deterministic and can be recorded as the release demo after the target contract smoke test passes.
